# 파트너 영상 서비스 · 청구 (PARTNER_VIDEO)

사용자 결정(2026-10-27):
- 파트너가 영상 1개를 올리면 비슷한 영상 10개를 fal.ai로 생성
- 비용은 파트너가 **계좌이체로 크레딧을 충전**하고, **관리자가 입금 확인** 후 충전
- 파트너 이용료 = **fal.ai 원가 × 1.4** (USD 기준)
- 파트너가 정한 가격으로 **고객용 청구서 링크**를 만들고, 고객은 **회사 계좌**로 입금(파트너는 직접 받지 않음)
- 고객 입금이 확인되면 **청구 금액 전액**을 파트너 정산금으로 적립, 관리자가 파트너에게 송금

## 크레딧 패키지 · 원화 가격 (2026-10-27 사용자 결정)
- 파트너는 **USD 크레딧 패키지**만 구매한다(기본 $50 / $100 / $300 / $500 / $1,000, `CREDIT_PACKAGES_USD`).
- 원화 결제 금액 = **공급가액** `ceil(USD × 환율)`원 + **부가세** `floor(공급가액 × 10%)`원.
  예: $50, 1 USD = ₩1,325.5 → 공급가액 ₩66,275 + 부가세 ₩6,627 = **₩72,902**.
- 환율 출처(순서대로 시도, 30분 캐시):
  1. **한국수출입은행 매매기준율**(`KOREAEXIM_API_KEY` 설정 시) — 영업일 11시경 고시, 주말·공휴일은 직전 영업일 값
  2. open.er-api.com (무료, 일 1회 갱신)
  3. Frankfurter(ECB 기준환율, 무료, 영업일)
  - 500~3,000원 범위를 벗어난 값은 거부, 모든 출처 실패 시 **가격을 제시하지 않음**(`FX_UNAVAILABLE`).
- 구매 요청 시 **환율·출처·공급가액·부가세·합계가 충전 요청에 고정 저장**되고, 관리자는 그 원화 합계로 입금을 대조한다. 크레딧은 패키지 USD 금액만큼 충전(부가세는 크레딧에 포함되지 않음).
- 환율 변동 위험: 요청 후 늦게 입금되면 고정 금액과 당일 환율이 다를 수 있다. 유효기간 강제는 없으며 관리자가 판단(거절 후 재요청 안내).

## 생성 파이프라인
```
파트너 브라우저 ── ① 업로드 URL 요청 ──▶ 서버(FAL_KEY) ── fal storage 업로드 URL 발급
       └── ② 영상 PUT (fal CDN, 최대 80MB) ──▶ fal storage
       ── ③ 작업 생성 ──▶ 서버: 크레딧 차감(원장) → 중간 프레임 추출(fal-ai/ffmpeg-api/extract-frame)
                                 → 비전 LLM(openrouter/router/vision, gemini-2.5-flash)이 장면 설명 + 프롬프트 10개
                                 → minimax/h3-max/image-to-video 10건 큐 제출(webhook)
fal ── ④ webhook(/api/webhooks/fal?token=…) ──▶ 서버가 fal에서 결과를 직접 재조회(본문 불신)
파트너 화면 ── ⑤ 15초마다 상태 조회(웹훅 누락·로컬 개발 대비 폴링 동기화)
```
- 실패한 클립은 그 클립 몫의 이용료를 **자동 환불**(1회). 분석 단계 실패 시 전액 환불.
- 업로드 권리 확인(인물·음악·상표) 체크 필수, 비전 LLM 지시문에 브랜드·수익 보장 표현 금지, fal 안전 필터 사용.

## 가격 (fal.ai 정가, 2026-10-27 확인)
| 항목 | 원가 |
|---|---|
| MiniMax H3 Max image-to-video 480p | $0.05/초 |
| MiniMax H3 Max image-to-video 768p | $0.08/초 |
| 분석(프레임 추출 + 비전 LLM) | 작업당 $0.02로 보수적 계상 |

- 2026-10-31까지 fal 프로모션가(35% 할인)가 있으나 **정가 기준**으로 계산(프로모션 종료 후 손해 방지). 가격 변경 시 `src/lib/video/models.ts` 수정.
- 이용료 = 각 부분 `ceil(원가 × 1.4)` → `분석 이용료 + 클립 이용료 × 10`. 예: 480p·5초 → 원가 $2.52, 이용료 **$3.528**; 768p·10초 → 원가 $8.02, 이용료 **$11.228**.
- 마크업은 `VIDEO_MARKUP_PPM`(기본 1,400,000 = ×1.4).
- 실제 fal 청구액은 출력 길이 오차(최대 +0.7초)·LLM 토큰에 따라 소폭 다를 수 있다 — 관리자 화면의 "fal 원가"는 정가 기준 추정치.

## 원장 (append-only, 분개마다 차대 일치)
| 사건 | 차변 | 대변 |
|---|---|---|
| 충전 입금 확인 | COMPANY_BANK | PARTNER_CREDIT(파트너) |
| 영상 작업 | PARTNER_CREDIT(파트너) | VIDEO_SERVICE_REVENUE |
| 실패 클립 환불 | VIDEO_SERVICE_REVENUE | PARTNER_CREDIT(파트너) |
| 고객 청구서 입금 확인 | COMPANY_BANK | PARTNER_INVOICE_PAYABLE(파트너) |
| 파트너 송금 | PARTNER_INVOICE_PAYABLE(파트너) | COMPANY_BANK |

- 크레딧 잔액 = −Σ PARTNER_CREDIT, 미지급 정산금 = −Σ PARTNER_INVOICE_PAYABLE. Builder Fee 배분 원장(70/30)과 계정이 분리되어 기존 대사에 영향 없음.
- 동시 차감은 파트너별 advisory lock으로 직렬화, 잔액 부족 시 402 `INSUFFICIENT_CREDIT`.
- 영상 작업과 연결한 청구서는 그 작업 이용료(환불 차감) 이상만 허용.

## 설정 (Vercel 환경변수)
| 변수 | 설명 |
|---|---|
| `FAL_KEY` | fal.ai API 키. 없으면 영상 생성 비활성(화면에 안내) |
| `FAL_WEBHOOK_TOKEN` | 웹훅 URL 토큰(임의의 긴 랜덤 문자열). 없으면 폴링만으로 동기화 |
| `VIDEO_MARKUP_PPM` | 기본 1400000 |
| `COMPANY_NAME`, `COMPANY_BANK_NAME`, `COMPANY_BANK_ACCOUNT`, `COMPANY_BANK_HOLDER` | 충전·고객 입금 계좌. 없으면 충전 요청·청구서 발행 비활성 |
| `CREDIT_PACKAGES_USD` | 패키지 금액(USD, 쉼표 구분). 기본 `50,100,300,500,1000` |
| `KOREAEXIM_API_KEY` | 한국수출입은행 환율 API 인증키(무료 발급). 없으면 무료 환율 API 사용 |

## 운영 절차 (관리자 `/admin` → 파트너 서비스)
1. **충전**: 은행 입금 내역의 입금자명/메모에서 `TOP-…` 코드를 찾아, 화면의 "입금 예정 ₩…(VAT 포함)"과 실제 입금액을 대조한 뒤 "입금 확인" 또는 거절. 크레딧 조정이 필요하면 USD 금액을 입력.
2. **고객 입금**: `INV-…` 코드로 입금을 찾아 "입금 확인" → 청구 금액 전액이 파트너 정산금으로 적립.
3. **파트너 송금**: 회사 계좌에서 실제 이체 후 금액·이체 기록을 입력해 "송금 기록"(미지급액 초과 불가).
모든 처리는 감사 로그(해시 체인)에 남는다.

## 알려진 한계 / 다음 단계
- 결과 영상은 fal CDN URL을 저장한다. 장기 보관이 필요하면 자체 스토리지(Vercel Blob/S3)로 복사하는 작업 추가 필요.
- 고객 청구서는 아직 USD 금액만 표시한다(크레딧 패키지만 원화·부가세 표시). 고객 청구서도 원화로 낼지 결정 필요.
- 세금계산서·현금영수증 발행, 부가세 처리는 미구현.
- 실제 fal.ai 호출은 FAL_KEY 설정 후 운영 환경에서 1회 시험 생성으로 확인해야 함(현재 테스트는 fal 게이트웨이 모의 객체 사용).
