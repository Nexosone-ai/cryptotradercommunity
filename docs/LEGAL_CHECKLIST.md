# 법률·규제 검토 체크리스트 (출시 전)

> 이 문서는 검토 항목 목록이며 법적 결론이 아니다. 관할권별 자격 있는 법률·세무 전문가 검토가 필요하다.

## 서비스 성격
- [ ] 비수탁형 자동매매 소프트웨어 제공이 각 관할(한국, 미국, EU 등)에서 가상자산사업자(VASP)·투자자문·투자일임·집합투자에 해당하는지
- [ ] Builder Fee 수취가 중개 수수료/거래 수수료로 해석되는지, 그에 따른 신고·등록 의무
- [ ] 레버리지 파생상품(무기한 선물) 접근 제공의 지역 제한 필요성(지오펜싱, 제한 국가 목록)
- [ ] Hyperliquid 이용약관·Builder Codes 정책상 제한 지역/용도 준수

## 봇 마켓플레이스
- [ ] 봇 등록자의 지위(투자자문업자 해당 여부), 등록자 책임·면책 조항
- [ ] 성과 표시 규정(과거 성과 표시 방법, 위험 고지 문구, 백테스트 표시 금지/구분)
- [ ] 봇 등록자 수익(70%) 지급의 세무 처리(원천징수, 1099/해외 송금 신고 등)

## 추천(파트너) 프로그램
- [ ] 다단계판매·방문판매법 등 다단계 보상 규제 해당 여부(2단계 구조)
- [ ] 금융상품 광고 규정, 파트너의 허위·과장 광고 책임 및 제재 절차
- [ ] 파트너 보상 세무(사업소득/기타소득) 및 KYC 필요성

## 개인정보·보안
- [ ] 지갑 주소의 개인정보 해당 여부, 개인정보 처리방침, 국외 이전(Vercel/Supabase 리전)
- [ ] 로그·감사 기록 보존 기간, 삭제 요청 처리와 회계 기록 보존의 충돌
- [ ] 쿠키 고지(필수 쿠키: 세션, 추천)

## AML/제재
- [ ] 제재 대상 지갑 스크리닝(OFAC 등) 필요 여부 및 도입
- [ ] 지급(payout) 수령인 KYC/제재 확인

## 약관·고지
- [ ] 이용약관, 위험 고지, 수수료 정책, 개인정보 처리방침 최종본 게시 (현재 `/docs`는 안내문, 법적 약관 아님)
- [ ] 수익 보장·무위험 표현 금지 점검(마케팅 포함)
- [ ] 분쟁 해결·준거법·책임 제한 조항
